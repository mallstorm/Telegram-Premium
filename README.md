# TelePremium 13.1.1 — Vault reset (723729)

[Скачать APK](https://github.com/mallstorm/Telegram-Premium/raw/refs/heads/build-output-vault-reset-723729/TelePremium_13.1.1_VaultReset_723729.apk)

Это приватный репозиторий: для скачивания войдите в GitHub под аккаунтом с доступом к mallstorm/Telegram-Premium.

1. Установите APK поверх текущего приложения, не удаляя его.
2. Откройте «Защита облака → Пересоздать облака всех аккаунтов».
3. Проверьте список Telegram-аккаунтов и служебных каналов и подтвердите удаление. Старые файлы в перечисленных облаках будут удалены навсегда. Обычные чаты, группы и «Избранное» целиком сохранятся.
4. Оставьте приложение открытым. После создания и синхронизации новых V3-облаков сохраните НОВЫЙ код восстановления вне Telegram. Старый Master Key для пересоздания не нужен. При прерывании используйте «Продолжить пересоздание облаков».

Установка обновления сама ничего не удаляет. Сами облака на реальном телефоне этими тестами не удалялись; выполнение запускается пользователем после проверки списка.

Проверки: 234 host checks; полная локальная Java/Kotlin/resource/DEX release-сборка прошла. Нативные библиотеки восстановлены байт-в-байт из предыдущего APK 723719, затем APK выровнен и подписан тем же ключом. Проверены пакет, versionCode, подпись, API-конфигурация, наличие интерфейса сброса и совпадение нативных библиотек. GitHub Actions не стартует из-за ограничений платежей/расходов аккаунта.
