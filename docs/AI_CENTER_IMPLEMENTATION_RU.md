# TelePremium AI Center

Репозиторий: `mallstorm/Telegram-Premium`. Рабочая ветка: `feat/folder-locks-dual`.
База: Telegram Android 13.1.1, upstream `3de37c8cfb039452be7398909461da6288babf15`.
Общий код центра подключён к классической 11.x и современной 13.x оболочкам.
Пакет Android: `com.telepremium.messenger`, архитектура APK: `arm64-v8a`.
Итоговая версия: `APP_VERSION_CODE=72600`, Android versionCode `726009`.

Основание: [полный текст приложенного ТЗ](AI_CENTER_SPEC_RU.txt). SHA-256 исходного PDF:
`4b5524c96877fb284e74c45f313405e1df08e1e6446adc26b18ffb82959e9483`.

## Технические решения

- **Локальная речь:** встроенное offline-распознавание Android 13+ с установленной языковой моделью; сегменты до 35 секунд. Никакого автоматического переключения на облако. Разметка говорящих ограничена возможностями установленного движка.
- **Облачная речь:** отдельное согласие для задания; выбранное подключение с OpenAI-совместимым `audio/transcriptions`, настраиваемая модель (по умолчанию `whisper-1`), ограниченные WAV-фрагменты до 10 секунд. Провайдер должен поддерживать этот endpoint. Локальная речь остаётся действием по умолчанию.
- **OCR:** Tesseract4Android 4.9.0 без Google Play Services; английская и русская модели включаются в APK на этапе сборки. Загрузчик проверяет закреплённые SHA-256 файлов моделей.
- **PDF:** PDFBox Android извлекает текст; Android PdfRenderer создаёт превью каждой страницы, Tesseract обрабатывает страницы без текста. Ограничения «первые 5 страниц» нет. Большие документы останавливаются по общему лимиту хранения с доступным частичным результатом.
- **Видео:** кандидаты кадров проверяются через короткие интервалы; сохраняются кадры с отличающимся перцептивным хэшем, а не равномерная выборка выходных кадров. Курсор и хэш последней сцены сохраняются.
- **Категории изображений:** локальная эвристика по подписи/OCR/описанию; смысловой поиск — отдельное явно подтверждаемое AI-действие. Идентификация людей по фотографиям запрещена в инструкциях модели.
- **Контекст:** шторка сразу показывает доступные в локальном индексе сообщения, затем по явному действию обновляет окно ±5 из Telegram без отметки прочтения. При отсутствии сети остаётся локальный контекст. Если оригинал удалён, сохранённая цитата остаётся с пометкой. Для воспроизведения архивного медиа оригинальное сообщение запрашивается отдельно, только для чтения.
- **Покрытие:** процент — доля обработанных проиндексированных сообщений. Неполная загрузка истории отмечается отдельно. Размер бюджета относится к одному проходу; следующий проход продолжает курсор. Индекс не обещает существование неизвестного числа удалённых сообщений.
- **Экспорт:** plaintext-файлы появляются после явной команды. HTML автономен и запрещает внешние ресурсы; текст экранируется, CSV защищён от формул. Анонимизация заменяет известные имена авторов/аккаунтов в метаданных, тексте и транскрипциях; пиксели изображений не редактируются — для такого экспорта предусмотрен режим без картинок. Архив центра всегда зашифрован.
- **Расписания:** Android JobScheduler запускает задания с учётом системных ограничений батареи; время запуска может сдвигаться системой. Отчёты автоматически в чаты не отправляются.
- **Защищённые данные:** secret chats не читаются; noforwards/исчезающие медиа пропускаются; сервисные peers облака исключены из чтения Telegram. Импорт облака доступен только для видимых незащищённых узлов в открытой сессии. Блокировка облака отменяет задачи и очищает связанные результаты центра.

## Проверки

Автоматически выполнены:

- JDK: `CenterIndexTest`, `CenterEnvelopeTest`, `CenterEvidenceTest`, `CenterTranscriptTest`, `CenterStatsTest`, `CenterExportTest`, а также пять существующих наборов Cloud/Player/Vault.
- 40 000 записей в тесте индекса, разделение аккаунтов, дедупликация, периоды и фильтры.
- Поддельные цитаты, совпадающие номера сообщений разных чатов/аккаунтов, страницы/таймкоды, длинные сообщения без отсечения.
- Сохранность нескольких цитат одного сообщения и **полной транскрипции за пределами цитаты** после очистки индекса.
- HTML/Markdown, анонимизация имён также внутри текста, CSV formula injection и порядок блоков.
- Применение overlay в отдельном чистом checkout; `verify_tg13.py`, 40 проверок классической оболочки, privacy/wiring и Java syntax.
- GitHub Source Check дополнительно выполняет существующие runtime-регрессии Vault/Media/Cloud/Xray и проверку native routing.
