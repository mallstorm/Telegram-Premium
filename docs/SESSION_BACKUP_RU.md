# Сессии: резервная копия (Центр TelePremium → «Сессии: резервная копия»)

**Сохранение.** Выбираются аккаунты, задаётся пароль (от 8 символов). Файл `.tpsession` шифруется (PBKDF2-HMAC-SHA256, 150 000 итераций, AES-256-GCM) и сохраняется через системный выбор места: Google Диск, «Файлы» и т. п.

В файл входят: ключи авторизации Telegram (`tgnet*` каждого аккаунта), состояние аккаунта (`userconfig`, настройки уведомлений), сетевой профиль и «Невидимка» аккаунта, при желании список ключей VLESS / Xray. Не входят: локальный кэш чатов (`cache4.db`) и секретные чаты, облачные чаты подгрузятся с сервера.

**Восстановление.** «Восстановить из файла» → пароль → список аккаунтов. Уже подключённый аккаунт заменяется своей сохранённой сессией, остальные занимают свободные места. Данные записываются при следующем запуске процесса, до чтения Telegram своих файлов, затем приложение перезапускается. Неудачное восстановление не мешает запуску.

**Предупреждения.** Файл вместе с паролем даёт полный доступ к аккаунтам. Одну сессию нельзя держать на двух устройствах одновременно: Telegram может её завершить. Если сессия уже завершена на сервере или аккаунт удалён, после восстановления потребуется обычный вход.

Проверки: `scripts/test_session_crypto.py` (контейнер, пароль, повреждённый файл, защита от `..` в архиве). Работа с реальными аккаунтами на телефоне не проверялась.
